1) The first MIDI file preserves all notes, key signatures, time signatures, and voice information from the source, but discards other information such as velocity and pedal events.- Tempo markings, rit. and accel should be discarded without affecting note timings or durations.- Tied notes are combined into a single note event combining their durations.- 8va, 8vb, etc symbols should be applied to the pitch value of the notes they cover.- Tremolo lines should be applied to the- There will be between 2 and 4 voices for the score. (1-2 voices for the treble, and 1-2 voices for the bass, with 1 each being the default). Place each voice in a separate track.- Block chords with arpeggiation symbols should be treated as normal blocked chords, as MIDI conversion performs a "lossy translation" by applying the arpeggiation that can land notes in the wrong place.- Grace notes / crush notes will occur. In virtually all cases, these notes should not push the note they're attached to forward. Instead, they should all fit in the last 16th note duration before the attached note.2) The second MIDI file contains the extracted melody. It should be a reduced version of the first MIDI file (whether derived from it or derived from the MusicXML - whatever's more convenient), with most notes deleted but the remaining notes staying on the same beat position as their counterparts in the original. Specifically, the remaining notes can change in pitch or duration, but not in start time.Extracting the melody follows a few rules:1. Locating the voice of the melody- If the treble and bass only have 1 voice each, the melody is guaranteed to be in the top (treble) voice.- If treble and bass have more than one voice each:x  + If there each voice is assigned a dynamic marking (p, mp, etc), the voice with the loudest marking is guaranteed to be the melody. Ties are broken by favoring the voice closer to the top. Else...  + There is a 50% chance that the melody is still in the top voice.  + If not, in most cases the melody is in the second voice from top.  + In very rare cases, the melody is the third voice from top.- The melody may switch between voices even when the total number of voices doesn't change.2. Extracting the melody line from the voice- The melody line is contained in the highest note of each chord (and all single notes)- All arpeggiation symbols should be removed; the note should be played on the beat position it's written in.- All grace notes should be deleted, and the notes they are attached to should remain in place.- All tremolo symbols should be removed. If the tremolo is chordal (between two sets of notes), it should be replaced with a single chord containing all unique notes for the duration of the tremolo. If the tremolo is on a single note, it should be replaced by a single note for the duration of the tremolo.3) The CSV file should contain the chord changes of the piece, in terms of the temporal scale of the generated MIDIs (beat position or timestamp, whichever is safer.- The current chord should be derived predominantly from the bottom voice of the bass clef.  + An octave in the bass or a low note on the first beat of the measure (perhaps tied from the last one) is guaranteed to define the bass of the current chord.  + The remaining chord information should be inferred from the remainder of the notes in the bottom chord, if possible  + If no unique notes beyond the octave are recovered, the remaining chord information should be inferred from the rest of the voices, with lower voices having higher precedence.
